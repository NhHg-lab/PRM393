# RUN BET – Human Racing Game

Flutter Android game in which the player bets virtual money on one or more of
four autonomous runners. Speed, hurdle outcome, recovery time, and final ranking
are controlled by the game engine; the player cannot affect the race after it
starts.

```powershell
flutter pub get
flutter run
```

## Game rules

- Initial balance: 1,000.
- Every screen is locked to immersive landscape with a 1920 × 1080 (16:9)
  design target.
- The player may bet different amounts on one or more runners in one race.
- The total stake is reserved as soon as a valid race starts.
- Only the champion's stake pays out at 4x because four runners have equal odds.
- Net profit = champion payout - total stake across all selected runners.
- Positive net profit shows Win, negative net profit shows Lose, and zero shows
  Break Even. Betting equally on all four runners is therefore break-even.
- All runners use the same speed and obstacle probability ranges.
- Every hurdle encounter generates new random probabilities: fall 8–25%,
  stumble 12–28%, and success receives the remaining probability.
- Initial speed, target speed, speed-change interval, obstacle outcome, and
  recovery duration are all randomized independently for every runner.
- A fallen runner recovers and continues; nobody is eliminated.
- All four runners finish before the result is settled.

## Add images and animation

Place backgrounds directly in `assets/images/backgrounds/` and runner media
directly in `assets/images/runners/`. GIF, animated WebP, and static PNG
are supported. Runner videos are muted, looped, and disposed automatically.

Create every screen background at `1920 × 1080 px` (16:9 landscape). Keep
important art inside the center 80% safe area because `BoxFit.cover` may crop
the outer edges on devices with different landscape ratios.

The installed legacy backgrounds are approximately 20:9. They are rendered
with centered `BoxFit.cover` and high filter quality on the new 16:9 target, so
their aspect ratio is preserved without stretching; only the outer left and
right edges can be cropped. The Home background is reused for Statistics and
Break Even until dedicated files exist.

Then edit only `lib/config/asset_paths.dart`. Example:

```dart
static const String raceBackground =
    'assets/images/backgrounds/race_track.png';
static const String winBackground =
    'assets/images/backgrounds/win.png';
static const String loseBackground =
    'assets/images/backgrounds/lose.png';

static const List<RunnerMedia> runners = [
  RunnerMedia(
    idle: 'assets/images/runners/red_idle.png',
    run: 'assets/images/runners/red_run.gif',
    jump: 'assets/images/runners/red_jump.gif',
    stumble: 'assets/images/runners/red_stumble.gif',
    fall: 'assets/images/runners/red_fall.gif',
    recover: 'assets/images/runners/red_recover.gif',
    finish: 'assets/images/runners/red_finish.gif',
  ),
  RunnerMedia(),
  RunnerMedia(),
  RunnerMedia(),
];
```

The installed running animations use transparent animated WebP assets generated
from the supplied GIFs by `tool/process_runner_gifs.py`.
Runner 3 also uses transparent fall and recovery WebP animations generated by
`tool/process_fall_gif.py`; the source sequence is split at frame 80 so the
controller can synchronize its falling and recovery states.

An empty state path falls back to that runner's `run`, then `idle`, then a
built-in Material icon. Missing files also fall back safely instead of crashing.

## Add sounds

Put audio directly in `assets/sounds/`, then fill the sound constants in
`lib/config/asset_paths.dart`:

```dart
static const String menuMusic = 'assets/sounds/menu.mp3';
static const String raceMusic = 'assets/sounds/race.mp3';
static const String countdownSound = 'assets/sounds/countdown.mp3';
static const String goSound = 'assets/sounds/go.mp3';
static const String jumpSound = 'assets/sounds/jump.mp3';
static const String fallSound = 'assets/sounds/fall.mp3';
static const String winSound = 'assets/sounds/win.mp3';
static const String loseSound = 'assets/sounds/lose.mp3';
static const String breakEvenSound = 'assets/sounds/break_even.mp3';
```

The asset directories are already registered in `pubspec.yaml`; no package or
source change is required when files are added directly to those directories.

## Quality checks

```powershell
flutter analyze
flutter test
flutter build apk --debug
```

On Windows, Pub cache is normally on `C:` while this project is on `D:`.
`android/gradle.properties` disables Kotlin incremental compilation to prevent
the known cross-drive relative-path cache failure.
